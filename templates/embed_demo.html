Embed KisaanBot on Any Website

This page demonstrates how agricultural portals, university websites (e.g. PAU, CCS HAU), state agriculture departments, and private agro-tech applications can embed the KisaanBot AI Assistant with a single script tag.

1. Embed Code Snippet

Place this tag just before the closing </body> tag on your website:

<!-- Include KisaanBot Embeddable AI Assistant Widget --> <script src="{{ request.host_url.rstrip('/') }}/static/js/kisaanbot-widget.js" data-api-url="{{ request.host_url.rstrip('/') }}/api/kisaanbot/chat" data-language="en" data-farmer-name="Farmer" data-theme="forest-green"> </script>

2. Try the Live Widget

Notice the floating KisaanBot widget in the bottom right corner of this external page! Click on it to test conversations in English, हिन्दी, or Hinglish. It communicates directly with the Kisaan Suvidha backend via clean JSON REST APIs.
